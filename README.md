# Real-Time Chat API

A Go backend project for learning and building a real-time chat system
using WebSocket.

## Learning-first workflow

This project is intentionally built incrementally.

OpenCode should explain concepts and make small changes rather than
generating the entire application at once.

See: - `AGENTS.md` - `project_status.md` - `docs/development_plan.md` -
`docs/architecture.md`

## OpenCode

Start OpenCode from the project root.

Run:

``` text
opencode
```

If this project has not been initialized with OpenCode yet, `/init` can
be used. Review the generated `AGENTS.md` rather than blindly replacing
project-specific instructions.

## First milestone

Build and understand a minimal WebSocket echo server.

Then incrementally build the Hub and multi-client broadcast system.

## Expected stack

-   Go
-   Gin
-   WebSocket
-   PostgreSQL
-   GORM
